# HTML-страница «О себе»

Тема: «Кулинар и фуд-блогер»

Цель

Освоить базовую структуру HTML-документа, семантические теги, списки, изображения и формы.

Реализация

На странице использованы:

*<header>, <main>, <section>, <aside>, <footer>*;
Разделы «Навыки» и «Проекты»;
Изображение с src, alt, width, height;
Форма обратной связи с полями имени, Email и сообщения;
Нумерованный и маркированный списки.
Оформление

Использована тёплая цветовая гамма: бежевый, коричневый и терракотовый.

Технологии

HTML5, CSS3.
